# WeCatch ReVanced Patches

WeCatch 안드로이드 앱(`com.daydreamer.wecatch`)을 위한 ReVanced 패치 번들입니다.
[ReVanced Manager](https://revanced.app)를 통해 스마트폰에서 직접 간편하게 패치할 수 있습니다.

---

## 🌟 주요 패치 목록

1. **CJK Smart Localization**
   - 기기 언어(한국어/일본어)에 맞춰 포켓몬 및 기술명을 자동 번역합니다.
   - 원격 설정 수신 시 영문 데이터를 디바이스 언어로 자동 대체합니다.

2. **Generation 9 Pokémon Support**
   - 9세대(899~1,025번) 포켓몬 데이터 및 필터 설정 탭("IX")을 추가합니다.

3. **Track IV Filter Toggle**
   - Track IV 화면 상단에 원형 FAB 필터 토글 버튼을 추가합니다.
   - 짧은 터치로 필터를 즉시 켜고 끌 수 있으며, 길게 터치 시 필터 설정으로 이동합니다.

4. **Teleport Floating Button**
   - 지도에서 포켓몬 선택 시 구글맵 툴바에 원클릭 순간이동 플로팅 버튼을 노출합니다.
   - GPS JoyStick 및 locationjoystick 앱을 지원하며, 모의 위치 권한(AppOps) 검사, 거리별 쿨다운 계산 및 패키지 가시성 쿼리를 자동 설정합니다.

5. **Pokémon GO 3D Icons**
   - 포켓몬 GO 공식 3D 고화질 모델 아이콘을 기본 적용합니다. (메인 화면 좌상단 버전 텍스트 터치로 전환 가능)

6. **Lock Orientation to Portrait**
   - 모든 주요 화면을 세로 모드로 고정하여 화면 회전 시 깜빡임 및 지도 마커 유실을 방지합니다.

---

## 📱 ReVanced Manager 사용 방법 (모바일)

1. [ReVanced Manager](https://revanced.app/download) 설치
2. 순정 [WeCatch 4.4.5 APK](https://apkpure.com/wecatch/com.daydreamer.wecatch) 다운로드 (설치하지 않고 보관)
3. 최신 [Releases](https://github.com/axbusters/wecatch-cjk-revanced-patch/releases/latest) 또는 본 저장소에서 `wecatch-cjk-revanced-patches-1.0.0.rvp` 다운로드
4. ReVanced Manager 실행 ➔ 하단 **Patches** 탭 ➔ **`+` (추가)** ➔ **Local** 선택 후 다운로드한 `.rvp` 선택
5. 하단 **Apps** 탭 ➔ **저장소에서 선택 (Select from storage)** ➔ `WeCatch 4.4.5 APK` 선택 후 **Patch** ➔ **Install**
